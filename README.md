# byte-log

> Learning yesterday. Forgetting today. Logging it anyway.

A personal knowledge log built from null, where I document what I learn,
understand, build, break, fix and discover along the way.

This isn't limited to one language or one field. It may contain programming
concepts, code, tools, technologies, problem-solving notes, useful commands,
random discoveries, mistakes and anything else worth remembering.

The goal is simple: **learn it, understand it, write it down, and keep it.**

## What You May Find Here

- 📚 Concepts and explanations
- 💻 Code and experiments
- 🧩 Problems I solved and mistakes I made
- 🔧 Tools and technologies I learn to use
- 📝 Notes worth coming back to
- 🌱 Anything else that becomes part of the journey

## The Journey

Starting from **null** and gradually building up.

There is no fixed roadmap and no promise that every entry will be polished.
Some notes may be simple, some may be wrong at first and some may eventually
be rewritten as I understand the subject better.

That's part of the point.

This repository is not meant to show what I already know.

**It's here to show what I learn.**
